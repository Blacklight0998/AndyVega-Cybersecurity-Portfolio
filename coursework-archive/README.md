# Coursework Archive

Small university exercises that I keep for completeness. They are not part of my main security portfolio.

| Exercise | What it is |
|---|---|
| [AES-EAX Cryptography Lab](./cryptography-lab/) | Two small scripts to understand authenticated encryption, nonces and integrity tags |
| [Web Security & Scraping Exercise](./web-security-scraping-exercise/) | A command-line program combining login validation, password hashing, regex and web scraping |

Both READMEs state their limitations, for example that reversible encryption and unsalted SHA-256 are not appropriate for storing passwords in a real system.
